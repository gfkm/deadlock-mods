# Deadlock mods by gfkm

**https://gfkm.github.io/deadlock-mods/** — downloads for gfkm's Deadlock mods: BetterTopBar, BetterMap and
BetterMap Camp Icons. Every download is a `.zip` holding the mod's `.vpk`, attached to a
[release](https://github.com/gfkm/deadlock-mods/releases), with its release text, an AI disclosure and the file's
SHA-256.

**Install:** unzip into `Deadlock/game/citadel/addons`. Each archive holds one `pakXX_dir.vpk` (BetterMap 01, Camp
Icons 02, BetterTopBar 03); if another mod already uses that number, rename the file to a free one. A mod manager does
this for you.

**AI:** these mods are built with AI tools; each card and release says how.

This repository holds only the page (`index.html`, `assets/`, `data/mods.json`, `images/`).

Fan-made mods, not affiliated with or endorsed by Valve.
