# Deadlock mods by gfkm

**https://gfkm.github.io/deadlock-mods/** — downloads for gfkm's Deadlock mods: BetterTopBar, BetterMap and
BetterMap Camp Icons. Every download is a `.vpk` attached to a [release](https://github.com/gfkm/deadlock-mods/releases),
with its release text, an AI disclosure and the file's SHA-256.

**Install:** put the `.vpk` in `Deadlock/game/citadel/addons` as its own pak, with a `pakXX_dir.vpk` number no other
mod uses. A mod manager does this for you.

**AI:** these mods are built with AI tools; each card and release says how.

This repository holds only the page (`index.html`, `assets/`, `data/mods.json`, `images/`).

Fan-made mods, not affiliated with or endorsed by Valve.
