Better HUD, same game

Mods that keep Deadlock's own look and add what the HUD leaves out. Every download is a .zip with the mod's .vpk, attached to a GitHub release, with its changelog and checksum.

Install

Unzip into Deadlock/game/citadel/addons. Each archive holds one pakXX_dir.vpk, numbered so these mods do not clash with each other (BetterMap 01, Camp Icons 02, BetterTopBar 03); if another mod already uses that number, rename the file to a free one. A mod manager does this for you.

About AI

These mods are built with AI tools, and each card says how. gfkm directs, reviews and tests every release in the game; the code is not presented as hand-written.
